# China Shopping — Telegram Mini App

Премиальная витрина шоппинг-посредника «Китай → Россия»: каталог товаров, корзина-заявка,
школа шоппинга, гайды по площадкам, китайско-русский словарь, калькулятор курса, платёжные инструкции.

## Структура

- `index.html` — разметка всех экранов (hash-роутинг `#catalog`, `#orders`, `#guides/poizon` и т.д.), стили v3
- `app.js` — вся логика (каталог, корзина-шторка, избранное, гайды, словарь, калькулятор, хаптика)
- `catalog-data.json` — подборка товаров: `[тип, название, описание, цена CNY|null, ориентир|null, ссылка, id]`
- `img/{id}.webp` — фото товаров (600×552, WebP): `auto-*` — автотовары, `furn-*` — мебель, `home-*` — товары для дома, `lei-*` — отдых и досуг
- `premium-v2.css`, `navigation-v3.css` — базовые стили и арт
- `sw.js` — service worker (network-first, кэш оболочки v2)
- `manifest.webmanifest`, `icon.svg` — PWA

## Ключевое в v3

- Фотографии товаров в карточках вместо иконок; цена в ¥ с пересчётом ≈ ₽ по курсу из `rate.rubPerYuan` (app.js)
- Бегущая строка условий под шапкой (курс, комиссия, доставка) — заполняется из того же конфига курса
- Корзина-шторка: «В корзину» открывает панель со степперами, суммой в ₽ и переходом в бота; бейдж счётчика в нижней навигации
- Хаптика Telegram (лёгкий отклик на кнопки, success при добавлении), expand/setHeaderColor/disableVerticalSwipes
- Шрифты Unbounded + Manrope (Google Fonts, с системным CJK-фолбэком)
- JS вынесен в `app.js` — CSP-хэш inline-скрипта больше не нужен пересчитывать

## Правила изменения данных

См. `DATA-AND-ORDERS.md`. Курс меняется только в `app.js` (`rate.rubPerYuan`) — бегущая строка,
карточки и калькулятор подхватят его автоматически.
